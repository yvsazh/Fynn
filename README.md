# Fynn

**Fynn** is the music generation model that powers the official website: **[FynnAI](https://fynnai.hackwhiz.net)**.

This repository contains the complete source code for the model, including:

- **Tokenization pipeline** — how musical data and prompts are converted into training/inference tokens  
- **Training system** — full training loop, optimization, checkpoints, and configuration logic  
- **Inference engine** — generation pipeline used to create music from user prompts  
- **Model architecture** — core neural network implementation and related components  

The goal of this repository is to provide everything required to train, run, improve, and deploy the Fynn music generation model.
